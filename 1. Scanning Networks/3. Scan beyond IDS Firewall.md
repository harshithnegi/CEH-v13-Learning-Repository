# 3. Scanning Beyond Firewall / IDS Using Evasion Techniques

## Introduction

Firewall and IDS/IPS evasion techniques modify the way scan packets are generated or transmitted.  
In this practical, different Nmap techniques are performed to understand **packet fragmentation, source-port manipulation, MTU, decoys, and MAC address spoofing**.

---

## 1. 🧩 Packet Fragmentation

Packet fragmentation breaks IP packets into smaller fragments, changing how the scan traffic is transmitted.

### Command

```bash
nmap -f 192.168.100.16
```

### Description

`-f` enables **IP packet fragmentation** during the scan.

### Output

```text
Nmap scan report for 192.168.100.16
Host is up.

PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
445/tcp  open   microsoft-ds
```

---

## 2. 🎯 Source Port Manipulation

Source port manipulation changes the source port used by Nmap for scan traffic.

### Command

```bash
nmap -g 80 192.168.100.16
```

### Description

`-g 80` sets the **source port to 80**.

### Output

```text
Nmap scan report for 192.168.100.16
Host is up.

PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
445/tcp  open   microsoft-ds
```

---

## 3. 📦 Maximum Transmission Unit (MTU)

MTU defines the size of IP packets; using a custom MTU can cause traffic to be transmitted in smaller fragments.

### Command

```bash
nmap --mtu 8 192.168.100.16
```

### Description

`--mtu 8` sets a **custom MTU value** for the scan.

### Output

```text
Nmap scan report for 192.168.100.16
Host is up.

PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
445/tcp  open   microsoft-ds
```

---

## 4. 🎭 Decoy Scanning

Decoy scanning makes scan traffic appear to originate from multiple source addresses.

### Command

```bash
nmap -D RND:10 192.168.100.16
```

### Description

`-D RND:10` generates **10 random decoy addresses** along with the actual scanner.

### Output

```text
Nmap scan report for 192.168.100.16
Host is up.

PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
445/tcp  open   microsoft-ds
```

---

## 5. 🔀 Random MAC Address

MAC address spoofing changes the MAC address used by the scanning system at the network interface level.

### Command

```bash
nmap -sT -Pn --spoof-mac 0 192.168.100.16
```

### Description

`--spoof-mac 0` tells Nmap to **generate a random MAC address**.

`-sT` performs a TCP Connect scan and `-Pn` skips host discovery.

### Output

```text
Nmap scan report for 192.168.100.16
Host is up.

PORT     STATE  SERVICE
22/tcp   open   ssh
80/tcp   open   http
445/tcp  open   microsoft-ds
```

---

```bash
# Fragmentation

# Decoy Scan
nmap -D RND:10 192.168.100.16

# Random MAC Address
nmap -sT -Pn --spoof-mac 0 192.168.100.16
```

> ⚠️ **Note:** These techniques should only be performed against systems in an authorized lab or where you have explicit permission to test.
